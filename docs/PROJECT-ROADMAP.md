# Roadmap

1. Identity, roles, organizations, factories, audit context.
2. Arabic/English item catalogue, units, suppliers, customers.
3. Warehouses, inventory movements, local SQLite cache/outbox, sync.
4. Bills of materials, production orders, consumption, finished goods.
5. Purchasing, sales, approvals, reporting, backups, monitoring, deployment.

Every increment needs PostgreSQL migration, server authorization/validation, SQLite changes, localized desktop UI, and tests.
